# KAKU

建築・リフォーム向けの見積もりワークスペース（PWA）。iPhone の Safari と Windows のブラウザで使えます。
公開：https://katsu1007.github.io/kaku-estimate/

## 2026-11-12 作り直し（2.0）

見た目と使い方を一新しました。案件を開くと **① 現場 → ② 部屋 → ③ 工事 → ④ 確認 → ⑤ 書類** の順番が出ます。

- 案件の管理（検索・並べ替え・複製・削除と元に戻す）、状態（見積中・提出済・受注・失注）
- 部屋の寸法から床・壁・天井・周長・巾木を自動計算（ドア・窓を引く。窓は寸法でも入れられる）
- 品目は単価マスターから選ぶ。材料はロス込み、板物は枚数に切り上げ、手間は正味
- 検算：別の計算の道筋で小計を出し直して照合。単価なし・数量0・消した部屋の参照などを知らせる
- 原価と粗利（材料は定価×掛け率、手間は単価×原価率、外注は入れた原価）
- 見積書・請求書・内訳書（印刷・PDF）、Excel（金額は式）、CSV
- 見積もりの履歴（第○版）と、前の版との比較
- 単価マスター（単価の変更、品目の追加、CSVの書き出し・取り込み）
- 保存は IndexedDB。まるごとバックアップ（前のKAKUのバックアップも読める）
- ダーク／ライト表示、最初の案内、見本の案件

図面の読み込み・照明の自動配置・3D は、新しい画面に移すまで **前のKAKU（`old/`）** で使えます。
前のKAKUの案件は、最初に開いた時に自動で引き継ぎます（設定から取り込み直しもできます）。

## ファイル構成

```
index.html        … 画面の枠
css/app.css       … 見た目（ダーク／ライト）
js/main.js        … 入口
js/app.js         … 起動・画面の切り替え・保存のまとめ役
js/calc.js        … 計算（画面に触らない。tests でテスト）
js/store.js       … 保存（IndexedDB）・前のKAKUからの引き継ぎ・バックアップ
js/home.js        … ホームと案件一覧
js/project.js     … 案件の①〜④
js/docs.js        … ⑤書類・履歴・比較
js/pages.js       … 単価マスター・設定・使い方・最初の案内
js/export.js      … Excel・CSV
js/master-data.js … 品目と単価の初期値（前のKAKUの計算エンジンの品目表から）
old/              … 前のKAKU（図面・照明・3D）
suido/            … 水道概算（別のアプリ）
vendor/           … pdf.js・three.js（前のKAKUが使う）
tests/            … 計算のテスト（node --test tests/*.mjs）
```

アプリを更新したら `sw.js` の VERSION を上げてください（古いキャッシュが消えます）。

## 前のKAKU（old/）の説明

## できること

- 案件の作成・複製・削除、現場情報の入力
- 部屋寸法から数量を自動計算（計算エンジン：最新の概算くんと同じ中身。品目は最初は全部「なし」で、やる工事だけ選ぶ方式）
- 見積明細の単価・数量の編集、税込合計の自動計算
- 図面の読み込み（DXF / JWW / PDF）。JWW・DXFは図面を表示して、簡易CADのように使えます
  - **部屋**：区画をタップして選び「1部屋にまとめる」（面積は合計、周長は外まわり）
  - **壁の解体**：壁の線をタップ → 解体の品目と高さを選んで追加（長さ×高さ、廃材も自動）
  - **カッター**：土間にカッターを入れる四角の角を2か所タップ → カッター・はつり・ガラ・掘削・残土・埋め戻し
  - **電気**：区画を選んで照明などを「列×行」か「間隔」で均一に並べる／壁の線を選んでコンセントなどを等間隔に並べる → 数が見積もりに入る
  - **部屋の用途**：電気の「器具に合わせて自動」で用途（事務室・会議室・トイレ・廊下など）を選ぶと、目標の照度（lx）に足りるように照明の数を決める（光束法の目安。天井が高い部屋は自動で増える）。並べた後に「約○○ lx」が出る
  - **3Dで見る**：図面の二重線を「厚みのある壁」にまとめて立ち上げる。壁・床・天井・ドア・照明などをタップすると、寸法・厚み・面積・仕上げ・数が出る。「表示」で壁・床・天井・器具・電気・配線と部屋ごとの表示、「仕上げで色分け」を切り替えられる。壁をタップして「ここに窓を足す」。「数量の根拠」で品目を選ぶと、もとになっている部材が光り、図面から測った数量と見積もりの数量を並べて見られる（見積もりの計算は変えない）
  - **開口を引く**：図面から見つけた開口（ドア＝幅×2.0m、扉の無い出入り口＝幅×天井高）を、壁の面積と巾木の長さから自動で引く。引いた時はポップアップで内訳を知らせ、案件ごとに「引かない」に戻せる。開口を見つけた部屋では「ドア（か所）」の数は使わない
  - **窓の寸法**：部屋の「工事内容」で窓の幅・高さ（mm）と枚数を入れると、その面積を壁から引く。3Dで足した窓も、面している部屋の壁から引く。寸法を入れた部屋では「窓（か所）」の数は使わない
  - **3Dの質感**：「表示」→「色」の「質感」（最初はこれ）で、床は仕上げに合わせた木目・タイル・シートなど、壁は塗り壁やタイル、ドアは枠・扉・取っ手、窓はサッシとガラス、照明は器具の形で描き、太陽の光と影を付ける。「部屋ごと」「仕上げで色分け」にも切り替えられる
  - **3Dの画質**：動かしている間は軽い「通常」の表示、指を離すと「高画質」に切り替わり、少しずつきれいになる（なめらかな輪郭、やわらかい影、角や物のまわりの自然な暗がり）。重い端末では枚数と解像度を自動で下げ、それでも重い時は通常の表示に戻す。「表示」→「画質」で「通常だけ」にもできる
  - **測る**：2か所タップで長さ（線の端や線の上に吸い付きます）
- 現場で測った寸法を部屋ごとに入れると、部屋ごとの平米と合計（㎡・坪）が出る。mm で入れても m に直す。L字・出っ張り・柱は「寸法を足す・引く」
- 部屋の「工事内容」から、図面がなくても寸法の四角に電気の器具を均一に並べられる
- 壁の解体は層を重ねて足せる（タイル → CBブロック → ラス下地モルタル など）。部屋の工事内容でも、図面の壁でも
- 廃材の処分は中身ごとに分けて計算（混載・コンクリートガラ・がれき類混合・石膏ボード・木くず。金属くずは一覧から）
- 土間のカッター・はつりは、使う時だけ見積明細の「＋ 一覧から追加」から足す（図面の「カッター」で描いても入る）
- 案件ボードで案件を長押しすると削除できる
- 写真・画像・PDFは「なぞって拾う」：寸法の分かる所で縮尺を合わせ、部屋の角をタップすると面積と周りの長さが出て、部屋になります
- 部屋ごとに「工事内容」（床・壁・天井の解体、下地、仕上げ、巾木、天井高、窓・ドア）を選べる
- メニュー（☰）から「材料・単価の一覧」（単価を直す・自分の品目を追加）、「一覧から見積もりに追加」（建具・電気・設備など）、「使い方」
- 見積書・請求書のプレビュー → 印刷・PDF保存
- CSV 書き出し（iPhone では共有メニューから「ファイルに保存」など）

## 見積書をPDFにするには（iPhone）

1. 「見積書PDF」（または「請求書PDF」）を押すとプレビューが出ます。
2. 「印刷・PDF保存」を押すと印刷画面が開きます。
3. 印刷画面の上の **共有ボタン** →「ファイルに保存」で PDF になります。

## オフライン動作

- ネットにつながっていなくても、起動・入力・計算・保存・図面読み込み・見積書プレビューはすべて端末の中で動きます。外部のサーバーには一切アクセスしません。
- オフラインで使えるのは、**一度オンラインで開いた後**からです。

## データの保存場所

- 入力したデータと読み込んだ図面は**この端末のブラウザの中**（localStorage）に保存されます。サーバーには送られません。
- Safari の「履歴とWebサイトデータを消去」をすると消えます。大事な案件は CSV で書き出して残してください。
- ホーム画面に追加した KAKU と、Safari で開いた KAKU は保存場所が別です（iPhone の仕様）。普段使う方を決めておくと安心です。

## 更新するとき

1. `index.html` などを差し替えてアップロードします。
2. `sw.js` の先頭の `VERSION` の数字を変えます（例：`2026-11-02.1` → `2026-11-05.1`）。
3. アプリを開き直すと新しい版になります（画面はネット優先で取りに行くので、つながっていれば基本すぐ反映されます）。
