# 新しい読み取り（js/reader2）の記録と採点

今の読み取り（前のKAKUと共通）は変えずに、別の部品として作っている新しい読み取りを、図面で回して確かめる。

```sh
sh tests/e2e/srv.sh
python3 tests/reader2/run.py <記録のフォルダ>                 # 実図面5枚（.real/）
python3 tests/reader2/run.py <記録のフォルダ> --fixtures       # 正解付きの試し図面も（KAKU_TESTS）
python3 tests/reader2/run.py <記録のフォルダ> --update         # 今の結果を基準にする
node tests/reader2.test.mjs                                   # 小さい図形での単体テスト
python3 tests/e2e/reader2.py                                  # 画面の切り替え（実図面が要る）
```

- 記録のフォルダは**リポジトリの外**に置く（お客さんの図面の中身が入るので）。
- `<名前>.answer.json` を置くと採点する。**正解は、人が確かめた物だけ**（こちらで作って採点しない）。形は `js/reader2/score.js` の頭に書いてある。
- 入れてよい変更の決まり：今の読み取りの区画が変わらない／本当の部屋を1つも「除外」にしない／正解付きの試し図面（図枠の無い図面）で印が1つも付かない。
